# Torneo de fútbol (React + Vite)

## Requisitos
- Node.js 18 o superior

## Ejecución
1. Clonar o descomprimir el proyecto
2. `npm install`
3. `npm run dev`
4. Abrir la URL que muestra la terminal ( http://localhost:5173)

## Video
https://youtu.be/PG2Xq2y9SHI

## Uso
Registrar partidos con el formulario, filtrar el historial por equipo,
eliminar resultados y ver la tabla de posiciones actualizarse automáticamente.
Los datos se guardan en memoria: se pierden al recargar la página.
